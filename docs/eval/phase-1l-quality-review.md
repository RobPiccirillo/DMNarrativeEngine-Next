## Independent-review remediation

The human verdict remains **PASS WITH DOCUMENTED LIMITATIONS**. Independent review reproduced two runtime defects: the explicit bundled Inject Arc action was incorrectly denied under the constrained broker, and manual Story generation could accept metadata-only provider output that became empty after processing. Both are remediated; they do not reopen the operational architecture or waive the documented narrative-quality debt.

The host chrome renderer now scopes authorization only around the registered Arc `injectArc` action, after the existing commit drain and context refresh. A private WeakMap associates genuine host-created mod contexts with their facade. The action receives a temporary model-call wrapper that reuses `callManualModel` and its private WeakSet request authorization. No request flag or public ModContext capability grants permission. Original, refreshed and unrelated contexts remain subject to the broker guard, and retained wrappers lose authorization when the action settles or throws. Automatic Arc callbacks/model calls remain suppressed. The real bundled `onActivate` ? registered button ? `onSelect` ? mod context ? broker ? dispatch path is covered for both profiles; current's ordinary mod calls remain available.

Swipe/Retry now reject an empty final display text after stakes metadata is stripped and before a variant is created. Scene Continue validates after both its existing scene-header stripping and stakes stripping, at every terminal completion branch, including current-profile tool-loop exits. No tags or placeholder prose are retained to create a false success. Valid visible output follows the existing success path. On stripped-empty Retry failure the previous retryable Story text is restored and no variant/pending commit is stamped; Swipe removes the temporary streaming slot and retains the existing variant; Continue restores the original prose/variant and reports failure rather than a successful continuation. No backend empty-content guard was weakened.

Validation: **338 affected tests across 28 files passed** (284 focused tests plus 54 chrome/mount tests).
